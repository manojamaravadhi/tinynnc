## Machine

- **CPU:** Apple M2 (8 logical cores; the benchmark is single-threaded)
- **RAM:** 8 GB
- **OS:** Darwin 25.6.0 (arm64)
- **Compiler:** Apple LLVM 21.0.0 (clang-2100.3.34.2)
- **Flags:** `-O2  -std=c11 -Wall -Wextra -Wpedantic -Iinclude`

## Method

- Each pass set is applied to a fresh copy of the model, and an execution plan is built once. After 20 warm-up runs, the pass sets are timed in 5 interleaved rounds (none, fold, ..., all, then again). Each round is about 0.1 s per pass set, so slow drift (CPU frequency, background load) affects all of them about equally. Mean and standard deviation are over all individual runs.
- Time covers one full forward pass, including allocating and freeing intermediate buffers.
- **Peak mem** = peak bytes of activations (intermediates + output) during one run, with liveness-based freeing on. Weights and the input are not included.
- **FLOPs** are estimates (2 per multiply-add, 1 per elementwise op).
- **max |diff|** = largest absolute difference from the unoptimized output on the same input.
- Weights are deterministic pseudo-random values (seed 42), and inputs are uniform in [-1, 1).
